Alien Invasion
Alien Invasion is a 2D shooter mini-game developed with Python and Pygame. In the game, the player controls a spaceship to shoot aliens, earns points by defeating enemies



Start:
Run main.by
    
playing method：
Enter key or click the Play button with the mouse to start the game

Press the Esc key to pause/resume the game

SPACE spacebar displays/hides the settings window

ASDW spacecraft movement direction key

Press the L key to fire bullets, press the K key to fire scattered bullets (1000 points or more are required, and 100 points will be deducted for each firing)

Press Enter to reload the game while paused or after the game has ended
